# Agent handoffs (moved)

Session handoffs for the next Cursor agent live in **`docs/handoffs/`**.

1. Open **`docs/handoffs/LATEST.md`** — points to the newest dated handoff.
2. Read that file (e.g. `docs/handoffs/2026-05-18-audit.md`).
3. For in-run art and rotation, read **`docs/GRAPHICS.md`**.
4. For bugs and decisions, read **`docs/tracking/BUG_TRACKER.md`** and **`docs/tracking/DECISION_LOG.md`**.
5. Read **`docs/handoffs/README.md`** for when and how handoffs are written.

**Important:** A new dated handoff is created **only when the user asks** after a session—not automatically after every task.
