## What this project is

**Mergehold TD** — mobile-first merge / tower-defense web game (Fort Guardian–inspired). Vite + React + TypeScript + Phaser 3 + Zustand. Vercel for frontend; Supabase planned later; optional API in `services/api`.

## Implemented in Phaser run

- Towers (3 types), merge on pad, 6 `+` pads
- Spike traps, 5 `!` pads, wave 2+
- Barracks + troops (blocker/ranged/burst by tier), wave 4+, max 10 troops
- Coin mills, wave 3+, income `12 × tier` on wave clear (before upgrade cards)
- Hero ability, map palette, roguelike 3-card upgrades
- Pause / 1.5x speed (top-left)
