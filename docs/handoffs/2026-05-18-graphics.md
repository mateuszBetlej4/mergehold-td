## RunScene — where graphics are applied

### `preload()`

Loads ~22 textures (Kenney PNGs, path/grass, SVG structures, bat/bomber SVGs, arrow). Anything placed in-run must be preloaded here (or via React `<img>` for HUD only).

### `drawMap()`

- **`drawGroundTiles()`** — `kenney-grass` 64×64 grid, tinted `palette.ground`.
- **`drawPathTiles()`** — `kenney-path-dot` stamped along path; tinted `palette.path`. **No** vector graphics stroke (removed — caused gray halo).
- **4×** `kenney-tree` — corner decoration, tinted HUD color.
- **Fort** — `fort.svg` at (195, 500).

**Not drawn:** build-pad Kenney art (circles only), trap-pad Kenney art (small circles).

### Rotation (`spriteFacingOffset`, `aimTowers`, `rotateSpriteToward`)

- Towers track nearest in-range enemy each frame.
- Enemies face next path waypoint while moving.
- Troops face combat target.
- Archer arrow uses right-facing offset; see **`docs/GRAPHICS.md`** for full offset table.

### Entities on field

| Entity | Asset | Scale / notes |
|--------|-------|----------------|
| Towers | Kenney PNG per type | ~0.58 + tier; badge overlay |

### React overlay (`PlayHud.tsx`)

**Keep Phaser preload keys and React paths in sync** when renaming files.

## Technical constraints

- **Phaser:** `this.load.image(key, path)` or `this.load.svg(key, path, { width, height })`. Use consistent keys in `towerAssetKeys` / `enemyAssetKeys`.
- **SVG in Phaser:** already used for structures/fort/hero; test mobile performance if adding many SVG instances.
- **Tinting:** `setTint()` / `setTintFill()` used on trees, hero, troops, SVG enemies; hit flash restores `enemy.tint` when set.
- **Rotation:** `spriteFacingOffset` + `rotateSpriteToward()`; do not assume all sprites face up.
- **Depth:** ground 0, path 2, trees 1, pads 3–4, entities ~7–18, React HUD z-index 2 on top. Full table: `docs/GRAPHICS.md`.
- **Scale reference:** towers ~0.58 base, enemies ~0.46, fort ~0.78, trees ~0.6–0.74.
