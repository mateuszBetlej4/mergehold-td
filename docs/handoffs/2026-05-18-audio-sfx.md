## Recommended architecture

### File layout (create)

```text
public/assets/
  source/freesound/          # originals + license notes (optional, gitignored if large)
  optimized/audio/
    music/
      menu-loop.ogg
      run-loop.ogg
    sfx/
      tower-archer-fire.ogg
      enemy-hit.ogg
      ...
  licenses/ASSET_CREDITS.md  # one block per clip/pack

src/
  data/sounds.ts             # sound catalog: key, paths, volume, category
  game/audio/
    audioManager.ts          # Phaser scene helper: play, music bus, guards
```

### Runtime wiring

1. **`sounds.ts`** — single catalog of sound keys (like `buildings.ts` for stats).
2. **`audioManager.ts`** — constructed with `RunScene`; reads Zustand `soundEnabled` / `musicEnabled` (subscribe or snapshot on play).
3. **`RunScene.preload()`** — `this.load.audio(key, [ogg, mp3])` for each entry.
4. **Hook points** — thin `this.audio?.play("enemy-kill")` at existing combat/build events (see table).
5. **React (optional phase 2)** — tiny `playUiSound("click")` only if same files are web-audio friendly; prefer keeping gameplay SFX in Phaser.

### Phaser pattern (reference)

```ts
// preload
this.load.audio("tower-archer-fire", ["/assets/optimized/audio/sfx/tower-archer-fire.ogg"]);

// play (respect toggle)
if (useGameStore.getState().soundEnabled) {
  this.sound.play("tower-archer-fire", { volume: 0.35 });
}

// music loop
const music = this.sound.add("run-loop", { loop: true, volume: 0.25 });
if (useGameStore.getState().musicEnabled) music.play();
```

Use **OGG primary** + **MP3 fallback** in load array for Safari.

## Sound event catalog — map to code

Priority: **P0** = MVP feel, **P1** = strong polish, **P2** = nice-to-have.

### Music

| Key | Moment | When to start/stop | Priority |
|-----|--------|-------------------|----------|
| `music-menu` | Home / Collection / Upgrades | Loop while not in `play` screen | P0 |
| `music-run` | Active wave combat | `create()` or first `spawnWave`; stop on `isGameOver` / leave play | P0 |
| `music-boss` | Boss wave (5, 10, 15…) | Crossfade or one-shot layer when `wave % 5 === 0` | P1 |
| `sting-wave-clear` | Upgrade overlay opens | Short flourish (~1–2s), not a full loop | P1 |
| `sting-defeat` | Fort HP → 0 | Once on `runEnded` defeat | P0 |
| `sting-victory` | Future win condition | Reserved | P2 |

**Direction:** Lo-fi fantasy / light medieval TD — not harsh EDM. Loop seamless; -14 LUFS-ish perceived loudness for music bus.

### Towers & projectiles

| Key | Moment | Hook (`RunScene.ts`) | Priority |
|-----|--------|----------------------|----------|

## Sourcing guide — where to find sounds

| Source | Best for | License |
|--------|----------|---------|
| [Kenney](https://kenney.nl/assets?q=audio) | UI bleeps, impacts, casual TD | Often CC0 — verify per pack |
| [Freesound](https://freesound.org) | Realistic hits, explosions, ambience | Filter **CC0** only for zero friction |
| [OpenGameArt](https://opengameart.org) | Fantasy loops, spells | Check CC0 / CC-BY |
| [itch.io](https://itch.io/game-assets/free/tag-music/tag-sound-effects) | Curated packs | Per pack |
| [Sonniss GDC bundles](https://sonniss.com/gameaudiogdc) | Large libraries | Royalty-free bundle license |

**Avoid:** NC-licensed, “editorial use only,” or MP3s with unknown origin.

### Search keywords (examples)

| Need | Freesound / OGA search terms |
|------|------------------------------|
| Archer | `bow release`, `arrow woosh`, `crossbow` |
| Cannon | `cannon fire distant`, `explosion small` |
| Magic | `magic zap`, `spell cast soft` |
| Enemy hit | `flesh hit`, `impact squish` |
| Fort damage | `wood crack`, `gate smash`, `stone impact` |
| Explosion | `explosion small`, `bomb fuse` |
| Trap | `spike`, `trap snap`, `metal click` |
| Troops | `sword swing`, `grunt attack` |
| Music menu | `medieval ambient loop`, `fantasy tavern` |
| Music run | `strategy game loop`, `battle ambient` |

Normalize all clips to similar peak (~-6 dBFS source), then set per-key `volume` in catalog (0.2–0.5 typical for SFX).

## Mixing & mobile rules

| Rule | Value |
|------|--------|
| Music bus volume | 0.2–0.35 |
| SFX bus volume | 0.3–0.5 (per-key adjust) |
| Max concurrent one-shots | ~6–8; drop duplicate keys within 50ms |
| Clip length | SFX &lt; 1.5s; music loops 30–90s |
| Total optimized audio MVP | Target &lt; **3 MB** |
| Autoplay | Only after user gesture (Play / Start run) — start music on first `play` enter |
| Speed 1.5× | Do **not** pitch-shift music; optional slight SFX rate ok |
