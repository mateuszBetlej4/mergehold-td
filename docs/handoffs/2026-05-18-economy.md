   - Wave 1–3: player can place 1–2 towers + one tier upgrade without starving.

## Two currencies

| Currency | Scope | Persisted? | UI |
|----------|-------|------------|-----|
| **Coins** | Single run | No | Play HUD `coins` |
| **Gems** (`softCurrency`) | Meta | Yes (`localStorage`) | Home, Upgrades shop, wave-clear overlay |

## In-run coins

### Starting wallet (`applyLoadout` in `RunScene.ts`)

```text
coins = 150 + permanentUpgrades.startingCoins × 15
if hero.role === "mage": coins += 25; rewardMultiplier += 0.2
```

| Loadout | Start coins |
|---------|------------:|
| Default (no meta) | 150 |
| War Chest L1 | 165 |
| Mage (no meta) | 175 |
| Mage + War Chest L1 | 190 |

### Sources

| Event | Formula / value | When |
|-------|-----------------|------|
| Enemy kill | `ceil(enemy.reward × rewardMultiplier)` | On death (`damageEnemy`) |
| Wave-clear pick | **+30** | `chooseUpgrade()` after card tap |
| Coin mill | `12 × tier` per mill | `collectCoinMillIncome()` on wave clear overlay |
| Gold Rush | `rewardMultiplier += 0.3` | Roguelike pick (rest of run) |
| Unknown upgrade target | +25 | `applyUpgrade` `default` branch |

### Sinks

| Action | Cost |
|--------|-----|
| Place tower | `baseCost` — Archer **20**, Cannon **35**, Magic **45** |
| Pad tier bump (tower/trap/support) | **15** per tier |
| Spike trap | **25** |
| Stone wall | **30** |
| Coin mill | **40** |
| Barracks | **55** |
| Healing shrine | **60** |

Tower max tier **5**; support max tier **3–4** (see `buildings.ts`).

## Meta gems

### Policies (locked)

| Policy | Decision |
|--------|----------|
| Wave clear | **DEC-020** — drip + `bestWave` update |
| Fort death | Completion bonus on top of drips already banked |
| Forfeit / abandon | **DEC-024** — keep drips; **no** fort bonus |
| Unlock gates | `progress.bestWave >= getUnlockWave(copy)` |

### Formulas (`useGameStore.ts`)

```ts
// Per wave cleared (once per wave, on upgrade overlay open)
waveClearGemDrip(wave) = max(3, floor(wave * 2))

// Fort destroyed only (claimRunRewards)
fortLossGemBonus(wave, coins) = max(8, floor(wave * 12 + coins * 0.08))
```

**Hook:** `RunScene.showUpgradeChoice()` → `recordWaveClear(this.wave)` when `wave > lastMetaWaveRewarded`.  
**Hook:** `RunScene.updateHud()` fort death → `claimEndOfRunRewards()` → `claimRunRewards(wave, coins, highestClearedWave)`.

### Cumulative drip if player clears waves 1–N (no fort bonus)

| Cleared wave | Drip | Running total |
|-------------:|-----:|--------------:|
| 1 | 3 | 3 |
| 2 | 4 | 7 |
| 3 | 6 | 13 |
| 4 | 8 | 21 |
| 5 | 10 | **31** |
| 10 | 20 | **110** (waves 1–10) |

### Fort loss bonus examples

| Death at wave | Coins held | Bonus gems |
|--------------:|-----------:|-----------:|
| 3 | 100 | max(8, 44) = **44** |
| 5 | 200 | max(8, 76) = **76** |
| 10 | 400 | max(8, 152) = **152** |

Full run to W10 clear then die on W11: drips through W10 (**110**) + bonus — research whether that’s too fast for shop.

### Permanent shop (`permanentUpgradeDefinitions`)

| ID | Base cost | Cost formula | Effect per level |
|----|----------:|--------------|------------------|
| fortHp | 35 | `35 + level × 35` | +18 max fort HP |
| startingCoins | 30 | `30 + level × 30` | +15 start coins |
| towerDamage | 45 | `45 + level × 45` | +8% tower damage mult |

**L0→L1 prices:** 35, 30, 45 gems. After one run clearing ~W5 (31 drip) + fort loss (~60), player can afford **one** upgrade — by design.

**Export:** `previewFortLossBonus(wave, coins)` for UI tooltips.

### Phase 2 — Design targets (propose in DEC-031+)

Example targets (tune to taste):

| Target | Guideline |
|--------|-----------|
| W1 | After clear: afford 2nd archer OR T2 on first pad |

| W5 | Boss killable with 2–3 towers; **≥50** coins entering W6 |
| Meta | 1st permanent upgrade by 2nd–3rd run; L2 by ~W8–10 total progress |
| Hoarding | Fort bonus should not dominate drip (or reduce `coins × 0.08` term) |
